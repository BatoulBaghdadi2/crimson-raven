# Crimson Raven Cruise

## Project Description
Crimson Raven Cruise is a luxury Mediterranean cruise booking and information platform developed for CSCI390: Web Programming. This web application provides an intuitive interface for users to explore curated cruise routes, detailed destination information, pricing tiers, and onboard experiences.

## Key Features
- **Responsive Design:** Optimized for desktop, tablet, and mobile viewing.
- **Dynamic Routing:** Built using ReactJS to provide a seamless page navigation experience.
- **Interactive UI:** Features custom grid layouts and CSS hover effects to enhance user engagement.
- **Project Structure:** Organized into distinct pages: Home, Destinations, Pricing, and Experience.

## Technologies Used
- **Frontend:** ReactJS
- **Styling:** CSS3 (Grid & Flexbox)
- **Deployment:** Vercel
- **Version Control:** Git & GitHub

## Setup Instructions
To run this project locally, ensure you have [Node.js](https://nodejs.org/) installed, then follow these steps:

1. Clone the repository:
   `git clone https://github.com/BatoulBaghdadi2/crimson-raven.git`
2. Navigate to the project directory:
   `cd crimson-raven`
3. Install the required dependencies:
   `npm install`
4. Start the development server:
   `npm start`
